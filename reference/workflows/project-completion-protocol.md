# Project Completion Protocol

When a project is marked complete, follow these 5 steps:

1. **Add entry to `~/.claude/complete-projects.md`** at the top with:
   - Completion date
   - Project path (if applicable)
   - Purpose and final state
   - Key files or deliverables
   - Live URLs (if applicable)

2. **Remove from Active Projects** in `~/.claude/project-index.md`

3. **Remove from priority table** in `~/.claude/project-briefs.md`

4. **Update brief status** — Keep the full brief in `project-briefs.md` but change status to "Complete"

5. **Close gaps** — Update priority numbers in both files to close any numbering gaps
