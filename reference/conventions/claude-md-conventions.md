# CLAUDE.md Writing Conventions

When creating or editing CLAUDE.md files, follow these conventions.

## Pronoun Rules
- Always use "USER" (or "the human") and "Claude" instead of pronouns
- Never use "I", "you", "me", "my", "your" in CLAUDE.md files
- This avoids ambiguity about who "I" or "you" refers to
- Example: "USER writes, Claude edits" (not "I write, you edit")

## Standard Sections (Project-Level)
- **Purpose** - What the project does (1-2 sentences)
- **Current State** - Phase, what works, what doesn't
- **Key Files** - Important files with descriptions
- **Commands** - How to run/test
- **Conventions** - Project-specific patterns

## When to Use
- **Global (~/.claude/CLAUDE.md):** Cross-project preferences, workflows, tool settings
- **Project-level:** Project-specific context, commands, file descriptions

See `conventions/project-folder-structure.md` for full template.
